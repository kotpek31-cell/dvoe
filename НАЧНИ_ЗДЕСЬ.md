# Двое: запуск за ~20 минут, только с телефона

Открывай сайты в браузере телефона с включённой **«Версией для ПК»**. Supabase из России может открываться только через VPN.

## 1. Supabase (5 минут)
1. supabase.com → **Sign in with GitHub** (заодно появится аккаунт GitHub; если его нет — сначала зарегистрируйся на github.com).
2. **New project** → имя `dvoe` → придумай **пароль базы** и сохрани его в заметки → регион Europe → **Create**. Подожди 1–2 минуты.
3. **Authentication → Sign In / Providers** → выключи **Confirm email** → **Save**.
4. **Project Settings → API Keys** → скопируй **Publishable key** (`sb_publishable_…`) в заметки.

## 2. Expo (1 минута)
expo.dev → **Sign up** с email и паролем. Логин и пароль понадобятся для сборки APK.

## 3. GitHub и установка (10 минут, почти всё делает скрипт)
1. github.com → **New repository** → имя `dvoe` → **Public** → отметь **Add a README** → **Create**.
2. Зелёная кнопка **Code → Codespaces → Create codespace on main**. Откроется редактор с терминалом внизу.
3. Сохрани `dvoe.zip` из чата в «Файлы». В редакторе в панели слева долгим нажатием на пустое место → **Upload…** → выбери `dvoe.zip`.
4. Вставь в терминал одну строку и нажми Enter:
   ```
   unzip -q dvoe.zip && cp -r dvoe/. . && rm -rf dvoe dvoe.zip && bash setup.sh
   ```
5. Скрипт спросит:
   - **строку подключения**: Supabase → кнопка **Connect** вверху → вкладка **Session pooler** → скопируй URI;
   - **пароль базы** из заметок;
   - **Publishable key**;
   - собрать ли APK → `y`, затем логин и пароль Expo. На вопросы EAS отвечай Enter или `Y`.
6. В конце скрипт покажет адрес сайта. Если он напишет «Включите сайт вручную»: **Settings → Pages → Source: GitHub Actions**, затем **Actions → «Веб-версия» → Run workflow**.
7. Останови Codespace: github.com → твой аватар → **Your codespaces** → **… → Stop**.

## 4. Установка на телефоны
- **Android (ты):** expo.dev → Projects → dvoe → Builds → открой готовую сборку → **Install** → разреши установку APK. В приложении: разреши уведомления; во вкладке «Сон» нажми «Открыть настройки» и включи доступ для «Двое».
- **iPhone:** открой адрес сайта в **Safari** → «Поделиться» → **«На экран Домой»**.
- Зарегистрируйтесь оба: один нажимает **«Создать пару»**, второй вводит код.

Если что-то пошло не так — пришли скриншот терминала или ошибки.
