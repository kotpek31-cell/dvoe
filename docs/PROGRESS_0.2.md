## Принятые решения (сверх ТЗ — ТЗ главнее, здесь кратко)
- Выпуск одной версией 0.2 (сайт + APK). Работа в ветке `v0.2`, в `main` — после «ок».
- Иконка: идея 4 «Ладошки» (две лапки голубая/розовая тянутся, между ними искорка). Из неё — весь комплект иконок, сплэш, значок уведомлений, фавикон, PWA.
- Нижняя панель: вариант Б3 «Капсула с подписью» — неактивные вкладки круглые островки со значком, активная растягивается в капсулу (значок + название). Переход — мягкая пружинная анимация ~0,3 с, не режет глаз; при «Уменьшить движение» — без анимации.
- Гардероб = инвентарь, один экран. Разделы: Внешность (тело, кожа, причёски, глаза) · Одежда (шляпы, лицо, верх, низ, обувь, спина) · Предметы (в руках) · Способности (одна надета).
- Новые категории: «Спина» (крылья, рюкзак), «Лицо» (бандана; позже очки, маски).
- Палитры по 10: одежда/глаза — уголь, молоко, клубника, вишня, абрикос, лимон, мята, небо, черника, лаванда; волосы — уголь, шоколад, каштан, карамель, блонд, рыжий, слива, розовый, голубой, седой. 5 тонов кожи. Значения — в chibi.ts.
- Вещи — данные в базе (таблица items, рисунок = слои SVG или картинка). Стили глаз — в коде движка лица.
- Наборы по кодам: Художник (берет, фартук, кисть с палитрой, чёрное платье, каре, глаза «Дымка» — эксклюзивные серо-голубые), Ангел (крылья с парением, нимб), Бандит (бандана на лицо, узи), «Мог» (способность). Core-коды — один человек на всё приложение; что дают — назовёт пользователь.
- Текст в окне кода: «Никто не знает, что будет…».
- Способности: «Объятия» бесплатно (защита от спама 10 с, пуш не чаще раз в 5 мин), «Мог» по коду, перезарядка 10 мин. Нельзя применять к спящему. Скулы в сцене «Мог» — тени (см. chibi.ts, opts.mog).
- Автообновление Android: добавить expo-updates (EAS Update) в этот APK.
- google-services.json в EAS env — НЕ в этот раз.
- Звук «мог-мог-мог» — пользователь пришлёт файл; остальные звуки генерировать кодом.

## Грабли этой сессии
- В облачной сессии Claude Code на репозитории npm открыт: `npm ci`, `npx tsc --noEmit`, `npx expo export --platform web` работают; скриншоты — Playwright (уже установлен) по собранному `dist` через маленький node-сервер. Временные экраны для скриншотов (`app/chibi-lab.tsx`) не коммитить.
- Node 22 запускает `tools/art/*.ts` напрямую (`node tools/art/catalog.ts`); после правок рисунков пересобрать — должны измениться и catalog.sql, и catalogStarter.ts.
- В песочнице Cowork npm закрыт (403) — tsc только в GitHub Actions/EAS. Добавить шаг `npx tsc --noEmit` в web.yml перед сборкой.
- Push из Cowork-сессии без репозитория в источниках сессии запрещён (403 от git-прокси).
- Design canvas: картинки только через загрузку ассетов; макет собирался генератором ниже + boards.py.
- Коннектор Supabase требует подтверждения для «опасных» команд (revoke, drop, delete — даже внутри тела функции) и через 60 с падает по тайм-ауту, ничего не применив. Применять частями без этих слов, а их — отдельным файлом через SQL Editor. Большие миграции тоже лучше дробить.
- Новые таблицы в public по умолчанию открыты anon/authenticated (default privileges) — RLS включать в той же миграции, что и create table.

### Шаг 1. База — применено в Supabase (1 октября 2026)
- `supabase/schema.sql`, раздел 10: items, inventory, locations + pair_locations, pairs.location, ability_casts; закрытая схема private: user_roles, codes (только отпечатки HMAC-SHA256 + соль `app_config.code_salt`), code_redemptions, code_attempts.
- Функции: redeem_code, cast_ability, pending_casts, mark_casts_seen, set_location, my_role, dev_find_user, dev_grant_item, dev_revoke_item, dev_create_code, dev_list_codes, dev_set_code_active, dev_stats, dev_list_developers, dev_set_developer. Триггер profiles_chibi_guard проверяет каждую надетую вещь (старый формат `{"kind"}` разрешён).
- `supabase/catalog.sql`: 36 вещей + 2 способности. В базе 38 строк, контрольная сумма совпадает с файлом.
- Владелец назначен. Коды занесены (4 шт.: Художник, Ангел, Бандит — Core; Мог — обычный). Сами коды — только у пользователя.
- Проверено локально (Postgres 16 + заглушки Supabase): повторный запуск, коды (обычный, повтор, 5 неверных → пауза, Core дважды), образ (чужая вещь/цвет/поле), «Объятия» и «Мог», пропущенные сцены, локации, роли, anon.
- Старые пользователи: образ НЕ переписывается в базе — приложение само собирает образ из `kind` (мальчик — вихор, худи, брюки, кеды; девочка — длинные, платье, бантик, сапожки; небинарный — пушистая, мятное худи).

**Осталось по шагу 1:** пользователь запускает `supabase/patch_0.2_finish.sql` в SQL Editor (dev_revoke_item, dev_set_developer и revoke прав у anon). До этого всё безопасно: функции без входа отказывают, RLS включён.

### Шаг 2. Чибики 2.0 — готово в ветке `v0.2` (1 октября 2026)
- `src/lib/palette.ts` — палитры и тона кожи; их же берёт `tools/art/chibi.ts`.
- `src/lib/catalog.ts` — каталог: встроенный `src/lib/catalogStarter.ts` (собирает `node tools/art/catalog.ts` вместе с catalog.sql) → кэш на телефоне → таблица items (при входе и обновлении профилей, не чаще раза в минуту; неизвестная вещь у партнёра — подтянуть каталог).
- `src/lib/art.tsx` — SVG-строка слоя → react-native-svg; токены цвета `@c`/`@skin` с `|d` `|l` `|k`; `<image href="https://…">` для готовых картинок.
- `src/lib/chibi.ts` — `Look`, `LOOKS` (образы по умолчанию), `lookOf(profile)` (старый `{kind}` → похожий образ), `dress()` (неизвестная обязательная вещь → по умолчанию).
- `src/components/Face.tsx` — стили глаз classic / lashes / sparkle / sleepy / azure, цвет глаз; моргание остаётся при «Уменьшить движение».
- `src/components/Chibi.tsx` — проп `look` вместо `kind`, `gaze` вместо `look`. Позы: idle, walk, run, wave, hug, cheer, jump, fallen, sleep; `mog` — скулы, `eyesClosed`, `still` — без анимаций (плитки). 9 анимируемых слоёв. Сам раз в 8–15 с оглядывается / потягивается / подпрыгивает. Крылья машут и чибик парит (тень внизу), нимб покачивается, волосы сзади качаются при ходьбе. Сон: шляпа, предмет, спина и бандана прячутся. Большой холст — только у слоёв с крыльями, нимбом и предметом в руке (память на Android).
- Сверено с макетом: рисунок совпадает один в один (скриншоты собранного сайта рядом с `tools/art`).
- Заодно: `npx tsc --noEmit` в `web.yml` (в `v0.2` — только проверка, без публикации), исправлены старые ошибки типов (TabBar, `absoluteFillObject` — на Android подложка карточки была без позиции), `supabase/functions` исключены из tsc.
- Тело (мальчик/девочка/небинарный) пока отличается только образом по умолчанию — как на макете.
