## Как устроено (новое)
- **Комната, меню:** `app/room.tsx` — одна кнопка вверху справа (`menuOpen`), фон-подложка закрывает меню, реакции — рядком в меню. Нижней панели и боковых кнопок нет. «К себе» — под верхней панелью, когда камера не на мне.
- **Камера комнаты:** свободная (`camX`) или «приклеена» к моему чибику (`camFollow` = интерполяция `x` ходока с зажимом по краям мира) и плавный переход `mix` (0 — свободная, 1 — за мной). Всё на native driver: камера едет в одном кадре с чибиком. `camNow()` — где камера сейчас; `freeCam()` — отцепить там, где есть; `camTo()` — на точку; `followMe()` — снова за мной.
- **Отдаление:** `zoom` (1 — обычно, `fitZoom()` — весь мир), масштаб вокруг низа экрана (земля остаётся внизу), формула сдвига — `worldMove`. Щипок двумя пальцами (PanResponder, `pinchMove`; отпустил почти без отдаления — снова обычный вид) или «Обзор» в меню (половина: при всём мире земля слишком мелкая). При отдалении < 0,86 — имена над головами (`RoomActor showName`, не уменьшаются: `unscale = 1/zoom`). Нажатие в обзоре — назад к себе. Сцены и игры сначала `unzoom()`.
- **Имена:** над головами только в обзоре; «инфо об игроке» — нажатие на чужого чибика (Sheet: в сети, «Дай пять», способности, «Показать», «Убрать бота»); «Кто здесь» — список (нажатие на заголовок комнаты или пункт меню). Свой чибик не перехватывает нажатия (`tappable={false}`), кроме игр.
- **Джойстик:** `src/components/Joystick.tsx` (угол и сила 0…1, мёртвая зона). Комната: `onSteer` — отрезок на ~1,6 с вперёд, новый — при смене направления (> 0,22 рад), скорости или раз в 1,1 с; отпустил — стоп на месте (команда `move` уходит в канал). Главная: `Walker steer` — так же. Флажок `joystick` (выкл.) в `prefs`, переключатель в настройках «Управление».
- **Ходьба:** `Mover.go(..., smooth)` — мягкий разгон и торможение (`Easing.bezier(0.3, 0, 0.25, 1)`), `now()` считает по той же кривой; в канал уходит `e: 1`. `Mover.stop()` ставит значения на расчётное место. `Walker` считает место по времени отрезка (`seg`) — без «отскока» на Android (там `stopAnimation` отвечает асинхронно).
- **Камера в игре:** касание во время переезда на арену не останавливает анимацию; эффект по `arenaPx` и фазе возвращает камеру на арену.
- **Ничьи:** `src/lib/games/rules.ts` — `ranksOf` (места с повторами), `isDraw`, `winnersOf`. Звездопад — равные очки; реакция — равные очки и лучшее время; КНБ — проиграли в одном раунде (`groups`); тыква — по выбыванию. Ушедшие — каждый на своём месте. `GameResult.ranks`, `roomGameFinish(..., ranks)`. Пьедестал — ступени с несколькими чибиками, «Ничья!», «Победа делится». Сервер — `patch_0.2_fix.sql` (проверено на локальном Postgres 16: ничья, общее первое место, старый клиент без ranks, неверное место).
- **Объятия:** `AbilityScene` — `HUG = { reach: 620, meet: 1050, second: 2350, release: 3400 }`, сцена 4,6 с; новая поза `reach` в `Chibi` (руки навстречу, подрагивают), у `hug` руки сжимают и отпускают; покачивание вокруг ног, прыжок при встрече.

## Грабли этапа
- Safari: `pointerdown` от пальца — не разрешение для звука; разрешают `touchend`, `click`, `keydown`. Слушатель, снятый после первого `pointerdown`, оставлял звук выключенным навсегда.
- iPhone берёт иконку уведомлений и экрана «Домой» в момент добавления сайта — новая иконка только после повторного добавления.
- Native driver: новые узлы `interpolate` на каждой перерисовке могут рвать нативную анимацию; то, что обязано исчезнуть, — убирать по таймеру.
- `stopAnimation(cb)` на native driver отвечает асинхронно — место ходока считать по времени отрезка.
- Плитки земли через одну зеркально = двойники и разрезанные швом вещи. Решение: середина — без вещей у краёв, боковые — свои варианты, зеркальность оставить только для стыковки земли.
- `clipPath` в SVG не принимает `<g>` — маска объёма — один `path`.
