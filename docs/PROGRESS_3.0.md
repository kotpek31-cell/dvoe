# «Двое» 3.0 — редизайн графики: что сделано и как устроено

Обновлено: 2 октября 2026. Ветка `redesign-3.0` (от `main`, коммит `bb9c6ce`). **Не выпущено**: в `main`, в базу и на телефоны ничего не уходило.

Задача пользователя: «всё, что связано с редизайном — графика, модельки, эффекты, анимации — переделать в максимум», тела чибиков — пропорциональнее, шеи короче, стиль — мягкий (объём, градиенты, без жёсткой чёрной обводки).

## 1. Главное

- **База не менялась.** Каталог вещей (`items`, `catalog.sql`, `catalogStarter.ts`) остался прежним. Новый вид получается при отрисовке.
- **Новых пакетов нет**, нативных модулей нет, версия в `app.json` прежняя (0.2.0) → на Android это уходит обычным обновлением (`eas update`), новый APK не нужен.
- Свойства и позы `Chibi` прежние — экраны, которые рисуют чибика, менять не пришлось (кроме мелких подгонок размеров).

## 2. Как устроено

### Тело 3.0 — `src/lib/body.ts`
Рамка прежняя 120×170, макушка на y = 24, подошвы на y = 156,5. Голова меньше (масштаб 0,66 от макушки), туловище поднято под неё, ноги и руки длиннее: рост около 2,5 головы вместо 1,7. Шея короткая.
Вещи каталога нарисованы под старое тело. При отрисовке слой вещи целиком переносится на новое место:

| Слой вещи | Что с ним делается |
| --- | --- |
| всё на голове (волосы, шляпы, лицо, маска) | `T_HEAD` — масштаб от макушки |
| `body`, `under`, `front`, `back`, `backFx` | `T_TORSO` |
| `legL`, `legR` | `legTransform(side)` — штанина тянется под длинную ногу |
| обувь | режется на y = 141: подошва и носок на месте, голенище и чулок тянутся вверх (`shoeTopTransform`) |
| `handL`, `handR`, `handFx` | `handShift(side)` — к новой ладони |

Руки, ноги, шея, голова, подушка и плед рисуются из `body.ts` (обычная запись каталога с токенами `@skin`, `@c`).
**Новая вещь рисуется как раньше** — под старое тело, в тех же слоях. Ничего дополнительно делать не нужно.

### Стиль 3.0 — `src/lib/artStyle.ts`
Накладывается на любую строку рисунка при отрисовке (`renderLayer` в `src/lib/art.tsx`):
- чёрная обводка `#2B2035` → тонкий контур цвета самой заливки, только темнее;
- плоская заливка → градиент «свет сверху слева, тень снизу»;
- фигуры с прозрачностью ≤ 0,35, с уже готовым объёмом (`vol()`), с заливкой `url(...)` не трогаются.

Зоны: `body`, `head` (голова уменьшена — линии не утончаем), `scene` (локации: свет строго сверху вниз, чтобы плитки комнаты сходились на швах).
Глаза рисуются без стиля (иначе теряется выразительность), лицо — `Face.tsx`: радужка и второй блик у больших глаз, двухслойный румянец.

### Анимации чибика — `src/components/Chibi.tsx`
Те же позы. Добавлено: голова качается отдельно от тела, прыжок со сжатием и растяжением, шаг с подъёмом колена, шире мах руками, сидение и сон под новое тело. «Уменьшить движение» учитывается, на скрытых экранах анимации стоят.

### Локации — `src/lib/locations.ts`, `src/components/scene/Location.tsx`
Все 12 мест × день/вечер/ночь: общий свет и глубина (дымка, затемнение к низу), звёзды с Млечным Путём, луна/солнце с ореолом, детали в каждом месте. Луг перерисован строкой, как остальные (`Meadow.tsx` удалён). Живое небо: мерцание звёзд, падающая звезда, облака; на лугу — бабочки, пыльца, светлячки.

### Эффекты и сцены — `src/components/Effects.tsx`, `scene/AbilityScene.tsx`
Сердца с ореолом и кольцом, конфетти дугой, искры, новый круг от касания земли (`Ripple`). «Объятия»: лучи, искры по орбите, свечение пола. «Мог»: молнии, вспышка с кольцом, объёмные черепа.

### Мини-игры и грибы — `room/games/art.tsx`, `scene/Mushrooms.tsx`
Тыква, звёзды, тучка, руки, грибы и корзинка — в стиле 3.0.

### Интерфейс — `ui.tsx`, `TabBar.tsx`, `AbilityButton.tsx`, `Aurora.tsx`, `Sheet.tsx`, `CastBanner.tsx`
Главные кнопки — с градиентом и светом по кромке; у карточек, плашек и панелей — свет по верхней кромке и мягкая тень; активная вкладка светится, значок подпрыгивает; кнопка способности светится цветом способности и «дышит», когда готова; на авроре — звёздная пыль.

### Макеты — `tools/art/chibi.ts`
`chibi()` собирает чибика 3.0 из тех же `body.ts` и `artStyle.ts`. Прежний — `chibiClassic()` (для сравнения «до и после»).

## 3. Стенд — `tools/stand/`
Проверка графики без `npm install` и без Expo: настоящие компоненты приложения собираются с подменами `react-native` и `react-native-svg` и открываются в браузере.

```
node tools/stand/build.cjs chibi     # позы и образы:  ?still=1&size=&poses=&looks=&bg=
node tools/stand/build.cjs items     # каждая вещь каталога на чибике:  ?cat=&size=
node tools/stand/build.cjs scene     # локации:  ?id=&time=&variant=&part=split&chibi=0
node tools/stand/build.cjs ability   # сцены способностей:  ?kind=hug|mog&blocked=1&time=&id=
node tools/stand/build.cjs fx        # эффекты, мини-игры, грибы
node tools/stand/build.cjs ui        # кнопки, карточки, вкладки
node tools/stand/build.cjs tiles     # плитки гардероба в своих обрезках:  ?cat=&size=
node tools/stand/build.cjs preview   # живой просмотр главной: место, время суток, образы, ходьба по нажатию, способности
python3 tools/stand/shot.py <адрес> <png> <ширина> <высота> <вся страница 0|1> [пауза, мс]
python3 tools/stand/frames.py <адрес> <префикс.png> <ширина> <высота> <мс,мс,...>
```

Результат — `tools/stand/out/<страница>.html` (в `.gitignore`). Грубая проверка типов без `node_modules`: `tsc -p tools/stand/tsconfig.json`, список известного шума — `tools/stand/types/known-noise.txt` (новых ошибок быть не должно).

## 5. Грабли

- Файлы, общие с `tools/art` (`body.ts`, `artStyle.ts`), должны быть **без импортов значений**: node запускает `.ts` без сборщика и не находит импорты без расширения.
- id градиентов в браузере общие на всю страницу: у каждого чибика, вещи, цвета, слоя и локации — свой суффикс. Одинаковые id с разным содержимым → цвета «перепутываются».
- Стиль 3.0 не накладывать на глаза и на фигуры внутри `clipPath`.
- В локациях свет только вертикальный: наклонный градиент ломает стык плиток комнаты.
- Маленькое свечение точкой с обводкой выглядит кольцом — рисовать радиальным градиентом (`spot()` в `Location.tsx`).
- **Android, память:** `<g opacity>` в react-native-svg рисуется через отдельную картинку размером со весь рисунок (у локации — весь экран, 5–10 МБ на группу). В локациях прозрачность групп при отрисовке переносится на сами фигуры (`restyle`, зона `scene`); в своих компонентах ставить `opacity` на фигуры, а не на `<G>`. Svg на весь экран ради мелочей (точки, искры) не делать — обычные `View`.
- **Телефон, раскладка:** у абсолютного ребёнка `width: '100%'` считается от области внутри отступов родителя (в браузере — от всей). Градиент под кнопкой — в обёртке `absoluteFill` без отступов (`GradFill` в `ui.tsx`).
- Внутренняя тень (`inset`) рисуется под детьми: если ребёнок закрывает весь элемент (градиент кнопки), её не видно — свет по кромке делать в самом градиенте.
- Каждый слой чибика — отдельная картинка в памяти. Плитки гардероба рисуют только нужное (`part` у `Chibi`): голова — без ног, рук и спины; низ и обувь — без головы.
